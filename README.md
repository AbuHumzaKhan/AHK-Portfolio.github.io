📖 Overview

The AHK Portfolio is a modern, fully responsive personal portfolio website designed for Data Analysts, Data Scientists, and Business Intelligence Professionals. It highlights skills, projects, certifications, experience, and interactive elements with an elegant dark theme and glassmorphism UI.

This portfolio helps professionals showcase:

Job Simulations

Data Analytics Projects

Professional Certifications

Interactive Dashboards

Contact Information & Resume Download

✨ Features
🎨 UI & UX Enhancements

Glassmorphism Design for a modern and minimal aesthetic

Smooth Animations with hover effects & transitions

Typing Effect for dynamic role highlighting

Responsive Design – works seamlessly on mobile, tablet, and desktop
