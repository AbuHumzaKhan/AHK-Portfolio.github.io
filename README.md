📖 Overview

The AHK Portfolio is a modern, fully responsive personal portfolio website designed for Data Analysts, Data Scientists, and Business Intelligence Professionals. It highlights skills, projects, certifications, experience, and interactive elements with an elegant dark theme and glassmorphism UI.

This portfolio helps professionals showcase:

Job Simulations

Data Analytics Projects

Professional Certifications

Interactive Dashboards

Contact Information & Resume Download

✨ Features
🎨 UI & UX Enhancements

Glassmorphism Design for a modern and minimal aesthetic

Smooth Animations with hover effects & transitions

Typing Effect for dynamic role highlighting

Responsive Design – works seamlessly on mobile, tablet, and desktop

🧩 Sections Included

Hero Section – Professional intro with social links & resume download

About Section – Skills, expertise, and career focus

Education & Certifications – Timeline with modal previews

Professional Experience – Interactive cards with achievements

Job Simulations – Forage virtual experiences for real-world exposure

Projects Showcase – GitHub integration with project highlights

Contact Section – Direct contact form and social media links

📊 Data Analyst Focus

SQL, Python, Power BI, Excel, ML integrated into portfolio highlights

Real-world case studies & dashboards for business intelligence

GitHub repositories linked for live project access
