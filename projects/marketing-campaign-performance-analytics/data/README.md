# Generated data

The CSV exports, SQL seed file, and SQLite database are generated locally by python/generate_data.py with fixed seed 20261026. They are synthetic, illustrative data and are not records from a real advertiser or platform.

Run the generator from the project root to create:
- campaigns.csv
- campaign_daily_performance.csv
- ../sql/seed_data.sql
- marketing_campaigns.sqlite

The public showcase commits source, documentation, and report previews. The full project bundle delivered with this build includes the generated CSVs, SQLite database, SQL seed file, and Excel workbook.
