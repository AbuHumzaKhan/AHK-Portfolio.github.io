# Retail Store Profitability & Assortment Optimization

Portfolio project by Abu Humza Khan.

This project analyzes a synthetic two-month retail operating environment across 8 stores and 60 products to support store profitability, assortment, replenishment, discount and returns decisions.

**Key modeled KPIs**
- Sales: $743,164.35
- Gross profit: $264,503.96
- Gross margin: 35.6%
- Units sold: 93,739
- Stockout exposures: 231
- Return units: 1,391

**Core analytical questions**
1. Which stores and categories create the most gross profit?
2. Which products combine profitability and velocity?
3. Where is inventory stockout exposure concentrated?
4. Which discount/return patterns deserve management attention?

**Important:** all data is synthetic and illustrative; findings are descriptive, not causal.

The complete downloadable project package contains CSV data, SQLite, Python generation/QA, SQL, Excel, Power BI DAX/M instructions and a dashboard preview.
