# B2B Customer Lifetime Value & Account Prioritization Analytics

A portfolio project for prioritizing B2B accounts using modeled customer lifetime value, retention risk, account health, and expansion opportunity.

**Business problem:** account teams have limited capacity, so current contract value alone is insufficient for deciding which accounts to protect, grow, or monitor.

**Dataset:** 1,200 synthetic B2B accounts with 12 months of synthetic monthly revenue. Generated specifically for this project with fixed seed 20261116. No real customer or company data.

## Key modeled portfolio metrics
- Annual Contract Value: $82.25M
- Modeled 24-month LTV: $98.97M
- High-value / elevated-risk accounts: 5
- Gross margin: 65.8%

## Included
Python QA pipeline, SQL schema and business queries, Excel executive workbook, Power BI DAX + Power Query M + model instructions, HTML dashboard preview, findings, data dictionary, assumptions, limitations and changelog.

**Native .pbix is not generated.** Power BI reconstruction assets are included in the project package.
