# Setup, Run, and Deployment Guide

## Requirements
- Python 3.10 or newer
- pip
- Excel desktop recommended for recalculating workbook formulas
- SQLite is included with Python

## Local setup

```bash
python -m venv .venv
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## Rebuild everything

From the project root:

```bash
python src/run_pipeline.py
python -m unittest discover -s tests -v
```

The pipeline regenerates the synthetic CSV, derived summaries, SQLite database, sample SQL seed, Excel workbook, HTML dashboard, chart PNGs, and QA outputs. Fixed seed: `20261029`.

## Open the report

Open `reports/dashboard.html` directly in a browser. The report is self-contained and embeds grouped aggregate data only; it does not expose individual appointment rows.

## Query SQLite

```bash
python -c "import sqlite3; c=sqlite3.connect('data/appointments.sqlite'); print(c.execute('SELECT status, COUNT(*) FROM appointments GROUP BY status').fetchall()); c.close()"
```

Use `sql/business_queries.sql` for stakeholder questions. `sql/seed_data.sql` contains the clinic dimension and a 120-row sample seed. The full reproducible 7,200-row seed is `data/appointments_synthetic.csv`, generated by `src/generate_data.py`.

## Excel

Open `excel/Appointment_Access_NoShow_Analysis.xlsx`. Formulas recalculate on open. Sheets include Executive Summary, Appointments, Clinic Summary, Specialty Summary, Lead Time Summary, and Data Dictionary.

## Publishing a static dashboard

1. Commit `reports/dashboard.html` and its documentation to a public repository.
2. Enable GitHub Pages for the intended branch/folder if hosting is required.
3. Open the exact published URL and verify KPI rendering, filter behavior, and responsive layout before claiming deployment.

This project package does not prove any hosted service is live. There is no backend API and no real patient data. If adapting the pattern to real healthcare operations, obtain organizational approval, minimize fields, apply access controls, follow applicable privacy and retention rules, and validate definitions with operations stakeholders.
